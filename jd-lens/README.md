## 部署到 GitHub Pages

1. 在 GitHub 建立用于作品集的仓库，或打开已有作品集仓库。
2. 将本目录中的内容上传到准备发布的位置；保留 `index.html`、`assets/`等相对结构，并保留 `.nojekyll`。只上传展示目录内容，**不要上传工作目录 `work/`、原始归档或完整资料库**。
3. 打开仓库 **Settings → Pages**，选择从分支发布（Deploy from a branch）。选择实际使用的分支，并指定已放置网页的根目录 `/` 或 `docs/`目录，保存。
4. 等 GitHub 完成发布，再打开 Pages 页面给出的地址，检查图片和PDF下载。首次发布前，本交付没有公开访问地址。

发布入口和目录选项已对照 [GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

**独立站：** 将本目录内容放在仓库根目录，或放在 `docs/`作为发布目录。

**与 StorePilot 合并：** 在统一作品集发布目录下建立 `jd-lens/`，将本目录全部内容放入其中，从总首页链接到 `./jd-lens/`。资源均为相对路径，不需修改 `base`；保留原有文件层级即可。合并后可为两个项目新增总首页，勿覆盖已有首页。
